# Texatron mk i

I believe a complete prototype has taken shape, but the scope of the the project feels nebulous. What is the Texatron mk i? Right now that's the inscription on the plank holding the strings (btw, i've got the double string done). Maybe i should just list out what is done
## Resonator
Plank with two tuneable strings, in close proximity like a mandolin. Rail for mounting electromagnet. Mandolin bridge, shitty nut.
## Transducer and Amplifier
Now thinking about transducer and amplifier as single unit. This makes more sense, as the two are pretty much one. Amplifier circuit is pretty tight, all done on protoboard, printing PCB in sight... Sending voltages out of DC coupled interface (Motu Ultralite). This could be considered part of the amplifier as well, it is essentially gain staging.

Regarding the transducer itself (electromagnet), still using peter's triple magnet. It works, but makes it hard to position without placing magnet under nodes. Powerful but very inconvenient. New magnet in the works
## Computational Material
Working in max/msp now, essentially additive synth with microtuning to account for string stiffness.
### i/o
using touch osc as interface. 

# Texatron mk i defined
So I guess the thing to do now is define this prototype. I should return to that filtering/dimensions paper... Gabriel suggested referring to the prototype as a research device, this makes sense.

**Texatron mk i: A computational composite wherein audio signal is expressed through electromagnetic excitation of a resistant material (resonant string). An open control system where the user tunes the computational signal to the fundamental of the string, affording easy access/control to discrete harmonics.**

This feels imprecise, but a good starting point.

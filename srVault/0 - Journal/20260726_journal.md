# current limits

## discreet signal paths
Rn we could be putting out 8 discreet signals, based on the outputs from the motu. Technically 10, but that’s including the headphone outs which have a different power rating than the analog outs.

Up until now we’ve been assigning each discreet path to a discreet string with a unique tuning, however, placing two magnets on each string would allow us to get even and odd harmonics out of each string, adding expressive potential without creating a debt in other areas (portability, $, interface limitations, setup/tuning stability) [[Every feature comes at a cost except those that are for free]]

fixed dependencies:
- analog outs: currently 8, but easy to expand (~40$/out)
- Transducers (~$20/magnet/cable/pcb)
- Amplifier (~$3/output)
Variable dependencies:
- interface/controller
- Resonant material
